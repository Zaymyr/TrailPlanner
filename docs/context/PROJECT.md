# Projet — Pace Yourself

## Identité

- **Pace Yourself** — [pace-yourself.com](https://pace-yourself.com). Ancien nom : Trail Planner.
- Fondateur solo : Faustin. Lancement commercial : octobre 2025.
- Plateformes : web (Next.js), Android (Play Store), iOS (App Store).
- Tagline : « Endurance strategy for trail & ultra ».

## Positionnement

- Outil de décision et de préparation pour les coureurs d'endurance — pas une app sociale ni gamifiée.
- Ton : sobre, crédible, « non-bullshit ».

## Deux publics

**B2C — coureurs.** Plans de course par section : nutrition, hydratation, allure, GPX, profil d'élévation, export PDF/GPX.

**B2B — organisateurs d'événements.** Le « livret coureur » : parcours GPX, ravitaillements, matériel obligatoire, retrait des dossards, partenaires, notifications push, statistiques de consultation.

Le livret coureur est à la fois un canal d'acquisition (coureurs) et le produit B2B.

## Tarifs

- **Coureurs** : achat unique d'environ 9,99 € par nouveau plan ; les plans existants restent gratuits. Bouton optionnel « Contribuer ».
- **Organisateurs** (par édition, négociable) :

- Première vente B2B : septembre 2026 (Duo Trail Vert).
- Objectif à 3 ans : 2 000 € net / mois.
